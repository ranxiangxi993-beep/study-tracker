# 研途 2.8 (47) 本地改版与审查记录

日期：2026-09-25。此文件记录代码与测试状态，不代表 APK 已发布。

## 设计决策

- 用户最终选择浅色背景，并提供粉白色统计页参考；默认主题改为雾白、淡玫瑰色点缀和轻微纸感纹理，不再使用深黑山景。
- 保留 React Native / Expo，不将 shadcn 网页组件强行嵌入 Android。参考其清晰状态、统一间距与可访问性思路。
- 首页优先放置模式、科目、计时与开始操作。月视图使用目标热力图，年度保留全部非零科目的引出线、占比和小时数。
- 首页设置与统计目标均输入小时，存储仍使用原有分钟键，避免破坏旧数据。
- 现有学习记录、计划、最低目标、学习/休息时长、自定义颜色、白名单及备考开始日期继续读取原有存储键。

## 修复与优化

1. 活跃计时增加持久化快照，暂停后重启不会把暂停时间算入学习；倒计时结算封顶，避免长时间后台后多记时长。
2. 当前学习段固定启动时的时长，编辑设置仅影响下一段。
3. 强力锁绑定学习时将截止时间交给原生，计时到点可由闹钟接收器/无障碍事件解除，不依赖 JS 恢复前台。
4. 应急解锁即时发出中断事件，按解锁时刻结算，而不是继续计时到切回首页。
5. 取消解锁手机时主动重新提升/重发流体云通知的逻辑；保留系统 Chronometer，不用静态剩余时间字符串充当倒计时。
6. 读取通知、闹钟、全屏提醒与电池优化的真实权限。自启动无统一读取接口，明确显示手动确认状态，不假装检测成功。
7. 白名单按手机可启动应用读取、去重、排序；不再因包名以 Google/OPPO 等前缀开头而整体放行普通应用。
8. 学习记录写入串行化，避免同时补录覆盖数据；编辑扣减记录保留负号，限制扣减范围，防止删除原记录后出现负数总时长。
9. 月份补录使用所选日期；历史分页防并发；切换统计周期防止旧请求覆盖新数据；跨年周视图读取正确日期总量。
10. 饼图标注按左右侧避让，图形可缩放但标签字号保持固定，保留全部非零科目。
11. 更新检查增加超时及资源文件名校验；更换默认背景不会删除用户外部文件。
12. 学科图标统一为淡彩底的语言、根号、笔记和学位帽，同步首页、计划及学习记录。首页科目改为图标上、文字下，保留文字名称和选中状态。
13. 新增自行填写的目标院校与可选专业，首页显示，备考目标页支持修改和二次确认清除。独立保存到 `academic_goal`，不改动原有日期、计划及学习记录。
